# Close out

Run when a chat on the project is ending ("we're done", "wrap up", "update the doc"). Nothing important should live only in this chat.

## Steps

1. Re-read the hub doc and the task sheet; they may have changed while you worked.
2. Go back through the whole chat and collect decisions, dated facts, work produced (with links), open questions, and follow-ups the user mentioned.
3. Write them to the hub doc as in **to-brief**, stale-text sweep included.
4. Update the task sheet: statuses, follow-ups as new rows (as in **to-tasks**), blockers.
5. Reply with:
   - 3–5 lines on what changed.
   - The next task and why it's next.
   - The exact line to paste into a fresh chat (usually `/next-task` plus the hub doc link).

## Rules

- Don't record suggestions the user didn't accept.
