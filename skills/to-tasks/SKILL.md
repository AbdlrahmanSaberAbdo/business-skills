# To tasks

Use when the user lists things to do, or a workstream needs breaking into steps. The sheet's columns and status values are defined in **setup-hub**. If the sheet is missing columns, add them at the right without moving data. If there's no sheet, ask for its link or run **setup-hub**.

## Steps

1. Read the sheet, plus the hub doc's Workstreams and Open decisions, so you don't duplicate rows.
2. Make each item a task someone can finish in one sitting and tick off. Split vague items ("marketing") into concrete ones ("Write first 9 Instagram posts").
3. Keep the user's wording for tasks they gave; fix typos and mention any rewording.
4. Set Workstream on every row. Set Blocked by only where order truly matters (MVP scope before the landing page, supplier before pricing, logo before website header).
5. Add the rows, then show them as a short table, flagging any item whose meaning you weren't sure of.

## Rules

- One action per row.
- Mark Done only what the user says is done, or what you just did.
