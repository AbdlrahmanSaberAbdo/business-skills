# Research options

Use when choosing between things that cost money or lock you in: store or website platforms, payment providers, hosting, booking and CRM tools, suppliers, couriers, contractors. Works with or without a hub doc.

## Steps

1. Read the hub doc's Brief if there is one. Budget, market, volume, payment methods and must-haves decide what "best" means. If volume is unknown, ask for an estimate (orders, users or bookings per month).
2. Name 2–4 realistic options, adding any important one the user missed.
3. For each, find **current** facts: plans and fees (per order, percentage, setup); the features the brief needs; limits and lock-in (contracts, data export, switching cost). Prefer official pricing pages, and the user's own dashboards when they're signed in (look, don't change). Date any secondhand figure.
4. Build one comparison table, same rows for every option.
5. Cost it at the user's realistic volume, in their currency, showing the arithmetic.
6. Recommend one, say what would change the answer, and name the next step.
7. Once the user chooses, record it with **to-brief**. Not before.

## Rules

- Say plainly when a fact couldn't be verified; never fill the gap with a guess.
- End with a Sources list.
- Legal, tax or investment choices: facts only, and say you're not a lawyer or financial advisor.
